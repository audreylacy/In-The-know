Notification help

Stay in the know

Turn on browser alerts so important class messages and deadline reminders can appear on your Chromebook screen.

01

For students

  1. Join your class with the code from your teacher.
  2. Click Enable alerts at the top of your dashboard.
  3. Choose Allow when Chrome asks for permission.
  4. Use Enable deadline reminders below your calendar for due-date alerts.
02

For teachers

  1. Open your teacher workspace and select a class group.
  2. Write a notification and click Send notification.
  3. Students who joined that class receive the message on their Chromebooks.
  4. Ask students to allow browser alerts so they can see messages away from the dashboard.

Chrome setting: If alerts were blocked, open Chrome Settings → Privacy and security → Site settings → Notifications, then allow this site.
