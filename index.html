Notification help

Stay in the know

Turn on browser alerts so important class messages and deadline reminders can appear on your Chromebook screen.

01

For students

  1. Join your school with the school code from a teacher, then join your class with its class code.
  2. Click Enable alerts at the top of your dashboard.
  3. Choose Allow when Chrome asks for permission.
  4. Use Enable deadline reminders below your calendar for due-date alerts.
02

For teachers

  1. Join an existing school with its code or create a school in your profile.
  2. Create or select a class group.
  3. Choose Selected class or Entire school in the announcement form.
  4. School announcements update dashboards while students are online; alerts with the app closed need the separate push service setup.

Chrome setting: If alerts were blocked, open Chrome Settings → Privacy and security → Site settings → Notifications, then allow this site.
